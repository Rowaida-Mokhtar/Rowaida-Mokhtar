Currently working on

My bachelor's thesis, Co-Manipulation of Virtual Objects Impact in Social VR Gaming (ongoing, due January 2027): I'm building a two-player networked VR tug-of-war game in Unity, where players appear as full-body avatars and pull on a shared rope. The game runs in two modes, pulling at the same time and taking turns, to study how sharing control of an object affects the multiplayer VR experience. The working prototype includes a garden lobby, a mirror for choosing avatars, game audio, controller vibration that responds to the opponent's pull, and a computer opponent for solo play.
